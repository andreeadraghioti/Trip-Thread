This project proposes a tool meant to facilitate the process of trip planning in the form of a web application which features a modern user-friendly interface. With the help of a few inputs given by the user about the trip he is planning, the Trip Thread application returns a tailored list of recommended attractions, a quick and efficient contextualized itinerary. In the application interface there is also the profile section where the user can save, export or delete the trips he has created, keeping the process organized.
In terms of developing the application, multiple full stack technologies were used, such as: Java with Spring Boot framework for the backend, Angular framework for the frontend, Keycloak for the authentication process, PostgreSQL for data storage and Docker for containerization. Two important external services used are Google Places API for retrieving the tourist attractions and OpenAI GPT via PandasAI for the selection process.
